# Origins: Off the Charts

**Origins: Off the Charts** is a Minecraft **1.21.1** Origins mod/addon that adds a collection of heavily customized origins with unique abilities, transformations, strengths, weaknesses, and progression mechanics.

The goal is to make each origin feel substantially different from normal Minecraft rather than simply giving players a few potion effects.

## Origins

The mod includes origins such as:

- Dragon
- Grasshopper
- Wight
- RPI Student
- Rubberman
- Kanima
- Vampire
- Werewolf
- Wendigo

Along with additional origins and mechanics added as development continues.

Many abilities and interactions are intentionally left somewhat unexplained. **Experiment and figure them out in-game.**

## Requirements

Built for:

- **Minecraft 1.21.1**
- **Fabric**
- **Origins**
- **Apoli**

Check the release/modpack information for the exact dependency versions required by each release.

## Installation

1. Install Fabric for Minecraft 1.21.1.
2. Install the required dependencies.
3. Place **Origins: Off the Charts** in your `mods` folder.
4. Launch Minecraft.
5. Select an origin and try not to discover its weaknesses at the worst possible moment.

For multiplayer, the mod and its required dependencies should be installed as required by the server/modpack configuration.
